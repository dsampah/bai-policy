# bai-policy

The published privacy policy for **BAI**, a research application used by
enrolled participants of a study approved by Sikt (the Norwegian Agency for
Shared Services in Education and Research), reference 196375.

This repository exists to give the policy a stable public URL, which Apple
requires for App Store Connect and TestFlight.

- **Published at:** https://dsampah.github.io/bai-policy/
- **Source:** [`index.md`](index.md)

## Publishing

GitHub Pages serves `index.md` from the default branch, repository root.
Settings → Pages → Source: *Deploy from a branch* → branch `main`, folder `/`.

## Keeping it true

The policy describes what the app actually does. If BAI's data handling
changes — a new permission, a new network call, a change to what the
participant roster stores — this document must change in the same week.
